# Workshop docs

This directory holds the workshop modules. Each module is a short, focused
lesson intended for ~20–30 minutes of hands-on time.

| # | Module | Goal |
|---|--------|------|
| 1 | [Introduction](./01-introduction.md) | Frame the problem and success criteria |
| 2 | [Setup](./02-setup.md) | Environment, keys, and repo layout |
| 3 | [Baseline agent](./03-baseline-agent.md) | Ship a working v0 agent |
| 4 | [Evaluation harness](./04-evaluation.md) | Build a small, reliable eval loop |
| 5 | [Optimization techniques](./05-optimization.md) | Prompts, tools, model, retrieval |
| 6 | [Comparing candidates](./06-comparison.md) | Pick a winner from evidence |
| 7 | [Wrap-up](./07-wrap-up.md) | Recap and where to go next |
