# Agent Optimization Workshop

A hands-on workshop for evaluating and optimizing AI agents — from a working
baseline to a measurably better one — using prompt tuning, tool refinement,
model selection, and evaluation-driven iteration.

## What you'll learn

- Frame an agent task with clear success criteria
- Build a small, reliable evaluation harness
- Diagnose failures with traces and metrics
- Apply optimization techniques (prompts, tools, model, retrieval)
- Compare candidate agents and ship the winner with confidence

## Audience

Developers and applied AI practitioners who have built a first agent and want
a repeatable way to make it better.

## Prerequisites

- Familiarity with Python
- Access to a chat-completion / LLM API of your choice
- Git and a recent Python (3.10+)
